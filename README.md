## 🔹 What is SciPy?

SciPy is an open‑source Python library used for **mathematics, science, engineering, and technical computing**. It is built on top of NumPy and provides additional functionality like:

✔ Optimization
✔ Integration
✔ Interpolation
✔ Linear Algebra
✔ Signal Processing
✔ Statistics
✔ Image Processing

